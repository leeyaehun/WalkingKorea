# WalkingKorea D-4 — 북촌 7경 포토스팟

실제 서울시 북촌산책 안내에서 7경은 북촌로11길 일대의 조용한 주거 골목이고, 남산 원경은 특히 6경의 특징이다. 따라서 7경을 허구의 대형 전망대처럼 만들지 않고, 한옥 대문·높은 담장·기와지붕·개량 공방과 전돌 벽체의 생활 풍경으로 구성한다.

## 구현

- 중심선 보행 거리 38.6m 지점, 반경 3.75m에서 선택적 포토 구도 제공. 기존 플레이어 위치와 이동·8인 WebSocket 서버 규칙 불변.
- 담장 위로 겹쳐 보이는 2~3채의 추가 한옥 지붕 레이어. 실제 회벽·목재 격자창·기와·서까래가 있는 3D 배경 구조물. 26채의 기존 한옥과 두 보행로와의 회전 직사각형 충돌을 검사한 뒤 배치.
- 벽에 부착된 작은 북촌 7경 안내판, 석재 바닥 표시, 도시 생활 설비함. 빛나는 게임 퀘스트 마커 없음.
- PC: F 사진 구도 맞추기, P 사진 저장. 모바일: 화면의 사진 구도, 사진 저장. 이름은 bukchon-7gyeong-postcard.png. 기존 산책 기록과 장소 6개 카운트는 유지.
- 작은 카메라 미니맵 표시는 기존 한옥 표시와 구분. 포토스팟은 새 길/POI 또는 강제 카메라 이벤트가 아님.
- 원래 5·6경 길과 7경 순환 골목, 원래 한옥 20채 + 추가 건물 6채, 여자 캐릭터, 낮·밤, 공개·비공개 멀티플레이, URL/후원 기능 변경 없음.

## 테스트

npm run build: D4 위치/투영/지오메트리/충돌/인터페이스 테스트 포함.
npm run test:multiplayer:integration: 로컬 Cloudflare workerd 실제 WebSocket 8개 시나리오.
Wrangler dry run.
실기기 브라우저 확인이 필요: 7경 명패·겹치는 지붕·모서리 담장·세로형 모바일 버튼·PNG·카메라 시야·실제 FPS.

이 구현은 사진/산책 고증을 참고한 게임 내 재구성이며 도로 좌표와 사유지를 측량하여 1:1 재현한 것은 아니다.
