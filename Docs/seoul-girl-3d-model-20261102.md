# 서울 산책자: 독립 3D 캐릭터 에셋 v1 (2026-11-02)

## 실제 모델
기존 여성 캐릭터를 실제 Three.js 3D 메시 약 90개와 독립 관절로 다시 조형.
갈색 단발·얼굴(눈/눈동자/하이라이트/볼/입)·아이보리 꽃핀·코랄
재킷·크림 스커트·베이지 크로스백·연보라 앵클부츠가
모두 공간적으로 입체다. 모델 전면은 +Z.
뒷머리·실제 두께 있는 주머니와 신발로 360° 관찰이 가능하다.

- 소스: \`src/characters/Girl3DModel.js\`
- 독립 웹 미리보기: \`/girl3d.html\`
- 동작: \`Idle\`, \`Walk\` 둘 다 유효한 QuaternionKeyframeTrack 기반
- 인터랙션: 마우스/손가락 드래그 360°, 확대/축소, 정면/옆면/뒷면,
  걷기·대기, 실제 binary glTF(GLB) 저장 버튼
- 다운로드: 스튜디오의 \`3D 에셋 GLB 받기\`를 누르면
  \`SeoulGirl3D_v1_walk_idle.glb\`을 생성한다.
  이 파일에는 실제 메쉬와 관절, 애니메이션 두 가지가 포함된다.
- 기본 게임의 2.5D 스프라이트, 기본 카메라, 캐릭터와 원격
  플레이어의 동작은 **아직 교체하지 않는다**. 사용자의
  디자인 승인을 받은 뒤 3D 게임 렌더링으로 전환할 수 있다.
- 캐릭터 카드의 기존 일러스트도 유지한다.
- 외부 에셋, 라이선스 불명 모델, 사진이나 네트워크 호출 없음.
- 테스트: 실제 3D 기하·관절 동작·특징 디테일·GLB 리그
  애니메이션의 정합성, 메인 게임 독립성.
