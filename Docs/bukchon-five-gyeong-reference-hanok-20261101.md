# WalkingKorea — 북촌 5경 왼쪽 전경 한옥 (사진 기반 단일 3D 에셋)

2026-11-01. 사용자 제공 실제 북촌로11길 5경 사진을 기준으로 **한옥 한 채**만 만든다. 위치는 기존 일자 거리의 아래쪽에서 언덕 위를 올려다볼 때 왼쪽 전경에 놓인 기존 주택 부지(서쪽, z 약 +46m)다. 실제 좌표·사유지 주소를 복원했다는 뜻은 아니다.

## 이 사진에서 반드시 표현할 요소

- 미색 회벽과 두꺼운 풍화 목재 기둥 및 정교한 사선 서까래, 거대한 박공 벽체
- 실제 곡률이 있는 검은 기와지붕: 경사면 약 460개, 기와 줄기, 둥근 수막새, 윗마루
- 창문 6개 이상의 진짜 목제 격자/한지 패널, 목재 공포/노출 서까래
- 사진처럼 석재 바탕에 수평 띠를 두른 밝은 회색 화강석 담장, 실제 높낮이가 있는 만자형에 가까운 꺾인 연속 격자띠
- 좌우 대칭이 아닌 쪽에 배치한 목재 양개문과 독립 기와 대문, 석재 발판, 생활등, 소박한 배수관
- 아파트나 관광 가게 간판은 넣지 않는다. 유료 외부 모델, 사진 빌보드, 타인 사유지 번호도 복제하지 않는다.

## 게임 통합

독립 파일 `src/world/BukchonFiveGyeongHanok.js`의 단일 에셋을 `BukchonWorld`에서 기존 한옥 생성기 대신 **딱 한 번** 사용한다. 기존 주택 좌표·회전·받침대 7.35 x 8.55m 유지. 여전히 한 번에 합쳐 그리는 기존 Three.js 메쉬/셰이더/재질/밤 조명을 활용하며 PC 및 모바일용 다운로드 에셋 추가 없음.

보행로, 5·6경 메인 도로, 7경 순환로, 총 기존 20채 집 위치, 별도 7경 집 6채, 8명 WebSocket와 비공개 초대 링크, 이름/도메인/후원 버튼은 변경하지 않는다.

## 품질 확인

`npm run build`, `npm run test:multiplayer:integration`, `wrangler deploy --dry-run`와 전용 에셋 테스트: 세부 부품 수, 실제 렌더 메쉬 유효성, 단일 부지, 통로 이격거리, 기존 집 20채 및 도로 불변.

마지막 수동 확인은 해당 기존 부지에 가까이 가서 **아래에서 위로 바라보는 카메라 방향**에서 회벽·지붕·기와·담장 문양이 실제로 읽히는지, 두 포지션에서 눈에 띄는 겹침이 없는지, 모바일 속도와 야간 창문을 직접 보는 것이다. 코드/단위 테스트만으로 사진과 완전히 똑같이 생겼다고 단정하지 않는다.
