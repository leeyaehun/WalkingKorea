# 북촌 47호에서 7경 골목 진입로까지 마지막 벽 (실제 배포화면 검수 후)

PR #44로 실제 두 동 배포를 확인했지만, 7경 서쪽 골목 입구 앞
약 2.76m에는 기존의 넓은 빨간 띠가 있는 평평한 크림 담장이 남아 있었다.
사용자가 요청한 43호와 같은 분위기를 유지하기 위해 이 실제 보이는
짧은 구간만 회색 화강석 블록, 붉은색과 미색의 꺾임 부조,
짙은 곡선 기와로 이루어진 낮은 담장으로 완전히 교체한다.

- 시작 z=4.14, 끝 z=6.90, 메인 도로 서쪽.
- 기존 7경 진입 z=1.5 및 폭 2.6m 좌우 개방 범위를 침범하지 않는다.
- 기존 담장과 새 담장을 동시에 렌더링하지 않도록 customFrontages 예약.
- 47호 두 동, 다른 39~43 스타일 세 채, 집터 20개,
  5/6/7경 도로, 멀티플레이와 카메라 상태 불변.
- 한옥 처마, 돌기초, 전돌 격자 장식은 동일 셰이더와 단일 월드 메시.
- 실제 최종 화면: https://walkingkorea.leeyaehun.workers.dev/?view=hanok47alley

테스트는 새 구간의 교체 여부, 옛 띠 담장 중첩 부재,
갈림길 개방, 성능 예산 및 돌/기와 부조 개수를 확인한다.
