# 북촌 5경 세 번째 한옥 + 앞집 깊은 기와 처마 (2026-11-01)

사용자 제공 북촌로11길 거리뷰 사진 세 장을 참고해 한옥 두 채의 외형을 고쳤다.
게임은 스타일화된 3D 북촌이며 실제 사유지/건축 도면의 1:1 복원은 아니다.

## 한옥 #10 — 이전 두 번째 집의 처마 보강

- 기존 큰 목제 격자창 2세트, 짙은 회색 꺾임 무늬띠 보존
- 앞 지붕을 7cm 돌출에서 **49cm 돌출**로 수정
- 지붕의 기울기가 비를 창문 밖으로 보내도록 내려오는 실제 곡선 기와와 낮은 하부 서까래, 흰 둥근 끝장식
- 본도로·건물 집터·멀티플레이 보존

## 한옥 #12 — 사진 세 장 기준 새로운 별도 에셋

- 원래 서쪽 index 12, z 약 +28.47 (이전 집 #10 z 약 +37.51에서 약 9m 윗경사)
- 중앙의 높은 목재 양개 대문, 좌우의 작은 목재 격자창
- 큰 **붉은 전돌색 문양띠**와 **밝은 ㄱ/C자 무늬**,
  아래에는 개별 회색 화강석 블록
- 약 52cm 깊은 기와 처마, **24개의 원형 기와 끝**, 입체 꽃잎 48개,
  흰색 둥근 서까래 끝, 낮은 어두운 처마 밑 목재
- 측면 박공, 오래된 목조 프레임, 배수로 및 계량기
- 다른 기본 한옥을 추가하는 것이 아니라 기존 딱 한 채를 교체. 집 위치 20채 불변.

## 검증

npm run build (기존 130개 테스트 + 6개 새 테스트), Wrangler dry-run,
실제 workerd WebSocket 8개 시나리오, Cloudflare 배포 커밋 확인,
실제 게임 화면의 처마 및 새 무늬담 확인. 모든 스마트폰 각도의
가림 여부와 FPS는 실기기에서 추가 확인해야 한다.
