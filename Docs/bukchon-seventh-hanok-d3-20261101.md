# WalkingKorea D-3 — 7경 골목 한옥 배치

D-1·D-2 디자인 시안을 바탕으로 C단계 7경 순환 도로에 실제 3D 한옥 건축 모델을 배치한 구현.

## 범위

- **A 전통 주택형:** 노출된 목재 격자창, 낮은 돌담, 기와지붕
- **B 높은 담장형:** 높은 사생활 보호 담장, 목제 대문, 기와 담장
- **C 마당이 보이는 한옥:** 실제 열린 입구, 돌 디딤길, 안채와 마루가 보이는 구성
- **D ㄱ자 모퉁이형:** 크기가 다른 두 지붕과 ㄱ자 안채 실루엣
- **E 개량 한옥 공방:** 큰 유리문, 나무 격자, 소규모 공방 간판
- **F 경사지 한옥:** 높은 석축, 돌계단, 경사지에 앉은 집

6채 모두 기존 Three.js 정적 BufferGeometry에 정밀 타일, 지붕 처마, 석축, 전돌, 목재 문과 창문을 진짜 다각형으로 구현한다. 2D 이미지/빌보드나 외부 상용 GLB를 사용하지 않는다.

## 골목 배치와 보행

- C단계 7경 순환 골목의 실제 거리별 지점 6곳에 1채씩 결정론적으로 배치. 기존 5·6경 거리 좌표 및 한옥 20채는 변경하지 않는다.
- 건축물 방향은 각 지점의 실제 골목 접선에 맞춰 정한다. 원래 도로와 다른 한옥의 회전된 바닥 영역과 **SAT 충돌 검사**를 통과해야만 배치한다.
- 각 한옥의 도로측 대문 자리에서는 C단계 임시 연속 돌담을 제거하고 실제 한옥 담장/문이 대신하도록 조정. 양쪽 접합부와 순환 통로는 열어둔다.
- PC/모바일 공통 판정과 8인 WebSocket 서버 이동 검사는 동일 도로 데이터를 그대로 사용한다.
- 기존 20채와 기존 조명, POI, 캐릭터, 후원/URL은 변경하지 않는다.

## 검수

npm run build, npm run test:multiplayer:integration, Wrangler dry run, 브라우저 확인.
수동 점검: 골목 양쪽에서 전체 순환, 한옥 정면을 보며 문/벽이 막혀 있지 않은지 확인, 지붕과 높은 돌담의 높이 및 골목의 일상성 확인, 8명 혼잡도, 기울어진 지형의 돌기단, 모바일 프레임률 확인.

*실제 북촌 7경 골목 지도와 1:1 좌표 대응하는 고증 복제품은 아님. D-4 포토스팟 시야/거리 연출은 별도 단계.*
